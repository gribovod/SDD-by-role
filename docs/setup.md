# Перше налаштування

Для кожного учасника команди, один раз, ~10 хвилин. Репозиторій уже має бути налаштований
адміністратором ([docs/customize.md](customize.md)).

| # | Що | Як |
|---|---|---|
| 1 | VS Code і Claude Code | [VS Code](https://code.visualstudio.com/) + розширення Claude Code; для схем у файлах — розширення **Markdown Preview Mermaid Support** |
| 2 | Git | Windows: https://git-scm.com/download/win, усе за замовчуванням; macOS / Linux — зазвичай уже є |
| 3 | Доступ до платформи | див. нижче — для GitLab чи GitHub |
| 4 | Склонувати репозиторій | у Claude Code: «склонуй <адреса репозиторію специфікацій> у <папка>». Якщо спитає логін і пароль — логін платформи, замість пароля — токен |
| 5 | Відкрити | VS Code → **File → Open Folder** → папка репозиторію → Claude Code. Перевірка: наберіть `/sdd` — мають з'явитися скіли |

## Доступ до платформи

**GitLab.**

1. GitLab → аватар → **Preferences → Access tokens → Add new token**, область **`api`**,
   строк — рік. Скопіюйте токен.
2. Збережіть токен у змінну середовища з назвою з `CLAUDE.md` (за замовчуванням
   `GITLAB_API_TOKEN`):
   - Windows: Пуск → «Змінити змінні середовища для свого облікового запису» → **Створити**;
   - macOS / Linux: рядок `export GITLAB_API_TOKEN=…` у `~/.zshrc` чи `~/.bashrc`.
3. **Перезапустіть VS Code.**

**GitHub.**

1. Установіть [GitHub CLI](https://cli.github.com/).
2. У Claude Code наберіть `! gh auth login` і пройдіть вхід через браузер.

**Токен — як пароль.** Не вставляйте його в чат з Claude, у файли чи в месенджери.
Claude бере його зі змінної середовища або з `gh` сам.

**Перед кожною роботою** скажіть Claude: «онови з сервера» — щоб працювати з останньою версією.
