# Як працює <продукт> зараз

Факти про поточну поведінку продукту, перевірені розробкою в коді. ПМ і БА спираються на
них, а не на пам'ять (конституція, розділ 3).

**Правила для цієї папки**

- Пише й виправляє **розробка**. ПМ і БА лише читають; якщо факт здається неправильним —
  питання розробці, а не правка.
- Кожен факт має джерело: де підтверджено (задача, гілка@коміт) і дату.
- Факт застарів через нову фічу — оновлюється в MR цієї фічі.
- Технічні деталі (таблиці, файли коду) — лише в розділах «Для розробки».

Файли з'являються, коли `/sdd-code-check` знаходить сталі факти, — **один файл на тему**,
наприклад:

| Файл | Про що |
|---|---|
| `roles.md` | Ролі, хто що бачить і може |
| `<сутність>.md` | Ключова сутність (замовлення, профіль, договір): поля, статуси, переходи |
| `platform.md` | Для розробки: стек, інтеграції, розгортання |
